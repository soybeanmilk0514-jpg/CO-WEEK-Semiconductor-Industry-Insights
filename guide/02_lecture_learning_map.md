# 02. Lecture Learning Map

## Selected 10 Lectures

| Layer | Lecture | Main Question |
|---|---|---|
| Quantum / device | 양자컴퓨터와 반도체 기술 | quantum hardware는 기존 반도체와 어떻게 연결되는가? |
| Materials / process | 반도체 소재의 이해와 트랜지스터 제작 기초 | material selection과 fabrication이 device behavior를 어떻게 만든다? |
| Memory / architecture | HBM에서 양자컴퓨팅까지 | compute bottleneck은 CPU→GPU→HBM→quantum으로 어떻게 이동하는가? |
| Industry / business | 미래자동차 시대의 기업가 정신 | 기술이 실제 산업과 사업으로 전환되는 과정은 무엇인가? |
| Materials | 실리콘 나노입자 | nanoscale Si material의 특성과 응용은 무엇인가? |
| Device physics | 트랜지스터 동작원리 | semiconductor switching의 물리적 기반은 무엇인가? |
| AI / semiconductor | 인공지능, 반도체를 만나다 | AI workload가 semiconductor architecture를 어떻게 바꾸는가? |
| Industry | 반도체 임팩트 | semiconductor가 산업과 사회에 미치는 영향은 무엇인가? |
| Circuit | CMOS 논리회로 입문 | transistor가 logic system으로 어떻게 확장되는가? |
| Quantum physics | 양자역학 비교적 쉽게 이해하기 | quantum computing의 물리적 개념은 어디에서 출발하는가? |

## Why This Combination Was Useful

열 개 강의는 서로 별개로 보이지만 실제로는 하나의 stack을 구성한다.

```text
Materials
  ↓
Device physics
  ↓
Transistor fabrication
  ↓
CMOS circuits
  ↓
Memory / HBM
  ↓
AI accelerators
  ↓
Quantum / heterogeneous computing
```

이 구조로 강의를 다시 정리하면서, 특정 기술을 외우는 것보다 **각 기술이 어떤 bottleneck을 해결하기 위해 등장했는가**를 보는 것이 더 중요하다는 점을 배웠다.
