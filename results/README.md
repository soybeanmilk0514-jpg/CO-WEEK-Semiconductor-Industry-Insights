# Structured Learning Records

This project did not generate experimental or simulation datasets.

The CSV files in this directory reorganize the learning experience into portfolio-friendly technical maps.

- `lecture_learning_map.csv`: 10 selected lectures and the technology layer they represent
- `computing_stack.csv`: device-to-architecture bottleneck map
- `reflection_matrix.csv`: lecture insight → engineering question → process/manufacturing relevance

These are learning records, not measured results.
